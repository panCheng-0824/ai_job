# OCR Demo 操作文档

本项目在 `ocr` 目录下提供了一个基于 `PaddleOCR` 的本地识别 demo，支持命令行运行与模块复用。

## 1. 前置要求

- Python 3.9+
- 已创建并激活虚拟环境（推荐）
- macOS / Linux / Windows 均可

## 2. 安装步骤

在项目根目录执行：

```bash
pip install -r requirements.txt
```

若未安装 `paddlepaddle`，请根据机器环境安装（CPU/GPU）：

- 官方安装指引：[https://www.paddlepaddle.org.cn/install/quick](https://www.paddlepaddle.org.cn/install/quick)

常见 CPU 安装命令：

```bash
pip install paddlepaddle
```

## 3. 快速开始

### 3.1 直接运行脚本

```bash
python3 ocr/paddleocr_demo.py --image /绝对路径/测试图片.png --lang ch --use-angle-cls
```

### 3.2 模块方式运行

```bash
python3 -m ocr.paddleocr_demo --image /绝对路径/测试图片.png --lang ch --use-angle-cls
```

### 3.3 导出 JSON 结果

```bash
python3 ocr/paddleocr_demo.py --image /绝对路径/测试图片.png --output-json ./ocr/result.json
```

## 4. 参数说明

- `--image`：输入图片路径（必填）
- `--lang`：识别语言，默认 `ch`
- `--use-angle-cls`：启用方向分类（图片有旋转时建议开启）
- `--output-json`：输出 JSON 文件路径（可选）

## 5. 输出结果说明

终端会打印每一行识别结果：

- 文本内容 `text`
- 置信度 `score`
- 检测框 `box`

JSON 示例结构：

```json
[
  {
    "text": "示例文本",
    "score": 0.9987,
    "box": [[10, 20], [100, 20], [100, 50], [10, 50]]
  }
]
```

## 6. 目录结构（模块化后）

- `ocr/models.py`：数据模型定义（`OCRSettings`, `OCRLine`）
- `ocr/core.py`：OCR核心逻辑（引擎创建、识别、结果归一化）
- `ocr/cli.py`：命令行参数解析
- `ocr/paddleocr_demo.py`：CLI入口与结果输出编排
- `ocr/README.md`：英文简版使用说明
- `ocr/操作文档.md`：中文操作手册（本文档）

## 7. 常见问题排查

- `ImportError: No module named paddleocr`
  - 执行：`pip install paddleocr`

- `Image file not found`
  - 检查 `--image` 路径是否正确，建议使用绝对路径

- 识别速度较慢
  - 首次运行会下载模型，后续会使用缓存
  - 可先关闭 `--use-angle-cls` 观察速度变化

- 中文乱码
  - 确保终端和文件编码为 UTF-8
  - JSON 输出已使用 `ensure_ascii=False`
