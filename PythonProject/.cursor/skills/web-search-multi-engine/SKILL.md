# 多搜索引擎联网检索技能

## 目标

在需要实时信息时，使用百度、谷歌、GitHub 进行分层检索，给出可追溯、可复查的答案。

## 触发条件

当用户请求包含以下意图时启用本技能：
- 联网搜索、查最新信息、查资料、查教程
- 查官方文档、版本更新、发布说明
- 查开源项目、仓库代码、Issue、PR、Release

## 搜索源选择规则

默认优先级（可按用户指令覆盖）：
1. `Google`：通用技术问题、英文官方资料、国际来源
2. `GitHub`：代码仓库、README、Issue、PR、Release
3. `Baidu`：中文语境、中文社区经验、中文教程汇总

若用户明确指定搜索源（如“只用 GitHub”），严格按用户要求执行。

## 执行流程

1. 明确检索目标：关键词、时间范围、语言偏好、是否要官方来源。
2. 先做主搜索源检索（1-3 条高相关结果）。
3. 用第二搜索源做交叉验证（至少 1 条）。
4. 提炼结论，保留不确定性，不凭空补全。
5. 输出结果时附上可点击链接。

## 查询词模板

- 通用技术问题：
  - `<主题关键词> official documentation`
  - `<主题关键词> latest version release notes`
- GitHub 代码问题：
  - `site:github.com <项目名> <功能关键词>`
  - `<项目名> issue <报错关键词>`
  - `<项目名> release <版本号>`
- 中文资料：
  - `<主题关键词> 教程`
  - `<主题关键词> 中文 文档`

## 输出模板

```markdown
结论：
- <1-3 条关键结论>

证据来源：
- [来源标题1](URL)
- [来源标题2](URL)

补充说明：
- <版本/时效性/适用范围>
```

## 质量约束

- 优先官方与一手来源（官方文档、官方仓库、发布说明）。
- 至少两个来源交叉验证关键结论。
- 信息冲突时，明确标注分歧与更新时间。
- 不输出无法追溯来源的“确定性结论”。
